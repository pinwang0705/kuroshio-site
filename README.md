# kuroshio-site

Kuroshio Athletics（黑潮運動）官網。靜態站，單一 HTML，零建置，GitHub Pages 從 main 根目錄發布。

正式站：https://kuroshio.pinchengco.com/

- `index.html`：整站，唯一來源。受眾是家長與選手。中文寫在 HTML 裡，英文寫在同一個元素的 `data-en` 屬性，**改中文一定要一起改 data-en**，不然英文版會停在舊版本。
- 服務是兩條各自獨立的線：招募專案（讓選手進得去）與地基會員（讓選手活得下來），可以只買一條。細節見 `~/Anson/projects/kuroshio/service-design/workshop-notes.md` 第九段。
- `CNAME`：自訂網域 kuroshio.pinchengco.com。刪掉會退回 github.io 網址。
- 對外聯絡：support@pinchengcaptain.com。統編 95435096。改在 `index.html` 最底的兩個常數。
- `assets/`：logo PNG 五張加 `og-1200x630.png`（LINE / FB 分享預覽圖，Abyss 底加 lockup）。
- `CLAUDE.md`：品牌硬規則與文案紅線，改站前先讀。

## 改對外資料
`index.html` 最底下的 `<script>` 有兩個常數：

```js
var CONTACT_EMAIL = "";
var TAX_ID = "";
```

填了才會顯示（結尾 CTA 與 footer），空字串整段隱藏，不會出現「待補」。

## 價格怎麼寫（2026-09-09 決定 11.1 到 11.4）
官網**不公開**招募專案與地基會員的金額。拿掉的有：金額、晚簽加價的六個數字、價格計算器、年級面板的全程總額、招募英文價目表。

保留的是入口價（體檢 NT$15,000）與價格的**結構**：兩條線分開計價可以只買一條、招募專案一次性、地基會員訂閱制、越早簽越便宜、晚簽加價有上限、兩個都買地基有折扣、體檢的錢往下折抵。金額一律寫「在諮詢時說明」。

## 諮詢是免費的（2026-09-12 決定 13.1）
諮詢從 NT$2,800 六十分鐘改成**免費 30 分鐘**。官網所有 2,800 與「諮詢折抵體檢」的文字都拿掉了，折抵只剩「體檢折進服務」。體檢 15,000 不變，而且是家庭在諮詢後回信說要做，才寄匯款資訊與問卷，收到款才排面談。理由與配套（怎麼防 no-show、怎麼篩）在 workshop-notes 第十三段。

要加價格回去之前先讀 workshop-notes 第十一段，那裡寫了為什麼拿掉。價目本身沒有變，只是不寫在官網。

## 接案量怎麼寫（2026-09-12 決定 12.5）
官網**不寫任何接案量數字**。價格區寫的是「招募階段同時能帶的人數有上限」，接著是時間算術的理由與「接不下就是不接，不接的標準公開」。

同一段原本結尾還有「接不下就是不接，不接的標準公開」，2026-09-12 決定 13.2 整句拿掉：不接的標準只在內部用，不接這件事只在面談時當面說。

之前寫的是「同時最多只接 8 位選手」。拿掉的理由：內部實際會超過 8 位（Paul 全職），把一個守不住的數字寫在對外頁面，跟整站「代辦會唬你、我們不會」的賣點衝突。「同時在手最多 8 位」現在只是內部產能基準，不是對外承諾。要加數字回去之前先讀 workshop-notes 決定 12.5。
